# VanNavBar 导航栏

基于 Vant4 的 NavBar 组件封装的导航栏组件，用于创建应用的顶部导航。

## 属性支持
> 插槽优先，非必要的属性请使用插槽。

| 属性名 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| border | Boolean | true | 是否显示下边框 |
| fixed | Boolean | false | 是否固定在顶部 |
| placeholder | Boolean | false | 固定在顶部时，是否在标签位置生成一个等高的占位元素 |
| zIndex | Integer | 1 | 导航栏 z-index |
| safeAreaInsetTop | Boolean | false | 是否开启顶部安全区适配 |
| clickable | Boolean | true | 是否开启两侧按钮的点击反馈 |
