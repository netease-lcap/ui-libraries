## Requirements

### Requirement: 栅格 layout 下固定列数且不应用查询断点

当 **`layout` 为栅格（grid）** 时，表单列数 SHALL **仅**由属性 **`columns`** 决定。SHALL **不**根据容器宽度在 2、3、4 列之间自动切换；**即使**「查询表单」开关为开启，SHALL **不**将查询断点列数映射叠加到 `columns` 之上。

#### Scenario: grid 宽度变窄仍遵循 columns

- **WHEN** `layout` 为 grid 且 `columns` 为 4，布局根节点宽度降至 800px
- **THEN** 表单项仍按 **4** 列栅格规则排布（溢出/滚动等行为遵循现有 grid 样式），SHALL **不**应用「992 ≤ w < 1200 → 3」或「w < 992 → 2」的查询断点映射

### Requirement: 非 grid 且开启查询表单时的响应式列数

当 **`layout` 不是 grid** 且「查询表单」已启用时，布局 SHALL 根据表单布局根节点的**内容宽度**（非仅视口宽度）选择行内表单项列数，阈值如下（边界按**大于等于**归入更高档）：

- 宽度 **≥ 1200px** 时，每行 **4** 列；
- **992px ≤ 宽度 < 1200px** 时，每行 **3** 列；
- **宽度 < 992px** 时，每行 **2** 列。

#### Scenario: 宽度 1200px 为四列

- **WHEN** `layout` 不是 grid、`queryForm` 已启用且布局根节点宽度为 1200px
- **THEN** 单行表单项按 **4** 列栅格排布

#### Scenario: 中等宽度为三列

- **WHEN** `layout` 不是 grid、`queryForm` 已启用且布局根节点宽度为 1000px
- **THEN** 单行表单项按 **3** 列栅格排布

#### Scenario: 宽度 992px 为三列

- **WHEN** `layout` 不是 grid、`queryForm` 已启用且布局根节点宽度为 992px
- **THEN** 单行表单项按 **3** 列栅格排布

#### Scenario: 再窄为两列

- **WHEN** `layout` 不是 grid、`queryForm` 已启用且布局根节点宽度为 991px
- **THEN** 单行表单项按 **2** 列栅格排布

#### Scenario: 容器宽度穿越阈值时更新列数

- **WHEN** `layout` 不是 grid、`queryForm` 已启用，且布局根节点宽度穿越 992 或 1200 边界
- **THEN** 列数 SHALL 更新为对应区间，无需整页刷新

### Requirement: 查询表单提供操作区具名插槽

「查询表单」启用时，表单 SHALL 提供 **具名插槽** 作为操作区域（用于查询、重置等控件 `props/插槽名` 在 `api.ts` 与文档中与实现一致）。

#### Scenario: IDE 可挂载操作插槽

- **WHEN** `queryForm` 已启用
- **THEN** 可在该具名插槽内放置操作区子组件；插槽语义在 `api.ts` 中可查

### Requirement: 非 grid 查询布局下操作区同行靠右且可整块换行后仍靠右

当 **`layout` 不是 grid** 且「查询表单」已启用时，操作具名插槽所在区域 SHALL 满足：

- 当可与当前行表单项**同排**展示时，操作区域在该行内 **靠右**（行尾）对齐；
- 当操作区域**整体**无法放入当前行剩余空间时，操作区域 SHALL **单独占用新的一行**，且在新行上 **靠右** 对齐；操作区内按钮 **不得** 被非预期拆到表单项网格的中间列中。

#### Scenario: 空间充足时与表单项同行靠右

- **WHEN** `layout` 不是 grid、`queryForm` 已启用且当前行剩余水平空间足以容纳操作插槽内容
- **THEN** 操作插槽与表单项处于同一换行行组内，且操作插槽相对该行 **靠右** 对齐

#### Scenario: 按钮过多时整块下移并靠右

- **WHEN** `layout` 不是 grid、`queryForm` 已启用且操作插槽内容宽度大于当前行可用于放置操作区的剩余宽度
- **THEN** 操作插槽 **整体** 移到下一行，且在该行内 **靠右** 对齐

### Requirement: 未启用查询表单时不施加查询布局规则

在未启用「查询表单」时，表单封装 SHALL **不**施加基于 992/1200 的查询列数约束，SHALL **不**强制渲染上述查询操作区布局容器；与现有 `layout`（含 grid）行为兼容。

#### Scenario: 关闭查询模式

- **WHEN** `queryForm` 未启用
- **THEN** 不应用本节「非 grid 响应式列数」与「操作区同排/换行」规则
